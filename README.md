# Геодиктант — тренажёр по странам и столицам

Интерактивный тренажёр к географическому диктанту: 90 стран и столиц Евразии,
Австралии и Океании на настоящей SVG-карте.

**Запуск:** откройте `index.html` в браузере двойным кликом. Сервер и интернет не нужны.

## Как поделиться с друзьями

- **Проще всего — файл `geodiktant.html`.** Это весь сайт в одном файле (~0,9 МБ):
  перешлите его в мессенджере или по почте, на компьютере откройте двойным кликом,
  на телефоне — через «Открыть в браузере» (Chrome, Safari). Отдельно `index.html`
  без папок `css/` и `js/` работать не будет — именно поэтому и нужен этот файл.
- Если пересылаете архивом ZIP — сначала **распакуйте** его, а не открывайте
  `index.html` прямо внутри архива.
- **Ссылка для всех:** в репозитории на GitHub откройте Settings → Pages →
  «Deploy from a branch», выберите ветку и папку `/ (root)`. Через минуту сайт будет
  доступен по адресу вида `https://<имя>.github.io/<репозиторий>/` — эту ссылку
  можно открыть с любого телефона или компьютера. (Для бесплатного GitHub Pages
  репозиторий должен быть публичным.)

## Возможности

- **Страны** — «Где находится Австрия?»: нажмите на страну. Маленькие страны
  (Мальта, Сингапур, Мальдивы, Люксембург, Бруней и др.) отмечены кружками-мишенями.
- **Столицы** — три варианта ответа:
  - *ввод с клавиатуры* — напечатайте столицу; регистр, «ё», пробелы и дефисы не важны,
    одна опечатка (две — в длинных названиях) засчитывается с пометкой;
  - *4 варианта* — карта приближается к стране, выберите столицу (клавиши `1`–`4`);
  - *«Чья это столица?»* — показывается столица, нажмите на её страну на карте.
- **«✓ Знаю, убрать из теста»** (клавиша `K`) — столица, которую вы точно знаете, убирается
  из текущего и всех следующих тестов «Столицы». Список отмеченных можно посмотреть
  и изменить в меню: «Известные столицы».
- **Страны + столицы** — сначала нажмите на страну на карте, затем выберите её столицу
  из 4 вариантов. За каждую страну два ответа.
- **С подсветкой / без подсветки** — с подсветкой ответы закрашиваются на карте, правильная
  страна мигает и подписывается; без подсветки карта остаётся чистой, результат — только в тексте.
- Автопереход к следующему вопросу; перемещение карты его не сбивает. Пауза — кнопка
  в верхней панели или клавиша `P`: останавливает и таймер, и автопереход.
- Регион: все 90 / Европа (39) / Азия (46) / Австралия и Океания (5). Азию можно учить
  частями: Ближний Восток (8), Аравия и Иран (7), Закавказье (3), Средняя Азия (5),
  Южная Азия (8), Восточная Азия (5), Юго-Восточная Азия (10). В режиме «4 варианта»
  неверные варианты берутся в первую очередь из той же части. Страны других
  регионов приглушены и не нажимаются.
- Счёт, номер вопроса, серия верных ответов, таймер, полоса прогресса.
- Результат: процент, время, лучшая серия, рекорд, список ошибок (по нажатию страна
  показывается на карте), «Работа над ошибками».
- Режим «Изучить карту» — наведите или нажмите на страну, чтобы увидеть название и столицу.
- Статистика в `localStorage`: рекорды по режиму и региону, точность, «слабые места»,
  ошибки последнего теста, выбранные настройки.
- Масштаб: плавный зум колесом мыши к точке под курсором, щипок на телефоне, кнопки
  `+` / `−` / «весь регион» (клавиши `+`, `-`, `0`). Перемещение — перетаскивание любой
  кнопкой мыши (левой, правой или средней). `Enter` — следующий вопрос, `Esc` — в меню.

## Структура

```
index.html          разметка
css/style.css       оформление (тёмная тема, анимации, адаптив)
js/data.js          ЕДИНСТВЕННЫЙ источник данных: 90 стран и столиц из списка
js/map-data.js      сгенерированные SVG-контуры стран (не редактировать вручную)
js/quiz.js          движок теста без DOM: вопросы, варианты, подсчёт
js/storage.js       статистика в localStorage
js/map.js           SVG-карта: отрисовка, масштаб/перемещение, подсветки, подписи
js/app.js           экраны и связь всех частей
geodiktant.html     весь сайт одним файлом (собирается tools/build-single.mjs)
tools/build-map.mjs сборка js/map-data.js из Natural Earth 1:50m
tests/              юнит-тесты и сквозные тесты в браузере
```

Названия стран и столиц взяты дословно из исходного списка (тест
`tests/unit.test.js` сверяет их с `tests/source-list.txt`). Для каждой страны в
`js/data.js` дополнительно указаны родительный падеж для вопроса «Столица …?»,
числовой код ISO для связи с контуром на карте и координаты столицы для отметки.

Контуры — Natural Earth 1:50m (общественное достояние), проекция Миллера.
Запорожская и Херсонская области, ДНР и ЛНР показаны в составе России (по правилам
диктанта); контуры этих областей — geoBoundaries (CC BY 4.0),
файл `tools/regions-to-russia.geojson`.

## Разработка

```bash
# пересобрать карту
cd tools && npm install && npm run build

# юнит-тесты (данные и движок)
node --test tests/unit.test.js

# собрать однофайловую версию geodiktant.html (после любых правок)
cd tools && npm run single

# сквозные тесты в Chromium (нужен playwright); TARGET=geodiktant.html — для сборки
node tests/e2e.js
```
